# Instructions to use condo

- install Anaconda - it brings a version of python along with its
- (base) indicate activation of anaconda
- (base) is kind of venv
- ```conda info``` to know about the conda
- ```conda env list``` 
- create new env ```conda create --name py310 python=3.10```
- ```conda activate py310```
- no need to use pip to install ```conda install seaborn``` seaborn is dependent on many library
- conda is little slow

- ```import numpy as np``` easy
- conda deactivate(2times)
- ```conda config --set auto_activate_base false```
